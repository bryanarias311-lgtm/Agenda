# 📅 Sistema Automático de Agendamiento - Bryan

Un sistema web moderno, responsivo e interactivo para gestionar citas y consultas desarrollado con **HTML5**, **Tailwind CSS** y **JavaScript**.

## 🚀 Características
- **Aviso de Bienvenida**: Titular dinámico *"Bienvenido al sistema de Bryan"*.
- **Registro Inicial**: Solicita el nombre del usuario al ingresar y muestra un saludo personalizado.
- **Categorías Simplificadas**:
  - Duda / Pregunta
  - Ayuda / Soporte
  - Otro
- **Formulario Ágil**: Selección de fecha, teléfono/WhatsApp obligatorio, correo opcional y descripción detallada de la cita.
- **Panel de Administrador Privado**:
  - Clave de acceso protegida: `2020`
  - Control de citas (Confirmar, Cancelar, Eliminar)
  - Métricas en tiempo real.
- **Persistencia**: Guarda toda la información de forma local mediante `localStorage`.
